大崎オーバルコート歯科・矯正歯科室

東京都品川区／JR山手線ほか 大崎駅北口から徒歩4分

JR大崎駅から徒歩4分。矯正歯科室を併設し、むし歯・歯周病の治療から予防、矯正、インプラント、訪問診療までを一つの医院で診ています。

院長インタビュー

お話を伺った方：医療法人社団KDS 理事長　小林 伸

予防について、どんな考え方で患者さんに接していますか。

治療より前に、日々のセルフケアで防げることが多いと考えています。当院がお伝えしている基本は、フッ素入りの歯みがき剤で1日2回・2分の歯みがき、歯間清掃を1日1回、舌みがきを1日1回軽く、という組み立てです。特別なことではありませんが、これを続けられるかどうかで数年後が変わります。

ジェットウォッシャーのような道具は、使ったほうがいいのでしょうか。

適切に使えば有効です。ただし万能ではありません。道具は足し算で、歯ブラシや歯間清掃の代わりにはならないと考えています。必要な方が1日1回を目安に足す、という位置づけでご案内しています。道具は歯科医院での使い方の指導とセットで、はじめて価値が出ます。

フッ化物の洗口はどんな方に勧めていますか。

むし歯のリスクが高い方と、矯正治療中の方には、診察の際にその都度ご提案しています。矯正装置が入っていると、どうしても磨きにくい場所ができるためです。お子さんについては、矯正中かどうかにかかわらず原則としてお勧めしています。

矯正歯科室を併設していることの利点は何でしょうか。

歯並びを整える過程では、むし歯や歯ぐきのケアが同時に必要になります。矯正と一般診療が同じ医院の中にあると、装置が入ったままでも予防処置やクリーニングをその場で受けていただけます。別々の医院に通っていただく手間がない、という点が一番大きいと思います。
